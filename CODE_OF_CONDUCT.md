# RepoGuard Community Code of Conduct

## Our Commitment
As team members and contributors to the RepoGuard project, we pledge to foster an inclusive, respectful, collaborative, and professional environment.

## Standards
- Encourage open communication and constructive feedback during code reviews.
- Respect diverse perspectives and varying hardware limitations.
- Adhere to engineering integrity: never falsify experimental results or disguise rule-based heuristics as trained machine learning policies.
- Prioritize project reliability, security, and reproducibility.

## Enforcement
Disagreements regarding architecture or interface definitions should be resolved through technical evaluation, benchmark data, and consensus among the project leads.
